## GodotPrompter

Before implementing any Godot system (movement, input, AI, UI, audio, animation, physics, tests…), check for a matching `godot-prompter:*` skill and invoke it first. The full index is in `godot-prompter:using-godot-prompter`. This applies to subagents writing Godot code too. The project targets Godot 4.7 (Mobile renderer).
