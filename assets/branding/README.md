# STARTING ELEVEN FC / SEFC

Primary crest created with the built-in imagegen tool for this project. The original transparent 1254 × 1254 output is preserved in `sefc-crest.png`. No external fonts are needed for the emblem lettering. Native PNG/ICO/ICNS files are resized/packaged from that same artwork by `tools/build_brand_icons.py`, preserving alpha.

- `sefc-crest.png`: primary logo, UI and source artwork.
- `sefc-icon.png`: 1024 × 1024 project icon.
- `sefc-splash.png`: 512 × 512 opening emblem.
- `sefc.ico`: Windows 16/24/32/48/64/128/256 px representations.
- `sefc.icns`: macOS 16–1024 px standard and Retina representations.

## Original generation prompt

Design the finished primary logo / application icon for an association football video game named STARTING ELEVEN FC, abbreviated SEFC. Asset type: production-ready square transparent-background game logo, 1024x1024 or higher. Use case: logo-brand. Exact and ONLY visible text: "SEFC" (S E F C, all four letters, perfect spelling). The game's existing visual identity is very dark midnight forest green (#09171d, #10282f), warm ivory (#f4f0df), and restrained champagne gold (#e9ce87); match this palette. Create one exceptional contemporary football-club crest with a powerful, beautifully proportioned shield silhouette, bespoke bold athletic SEFC lettering as the dominant element, a refined geometric association-football motif and an understated visual nod to the number eleven using two upright strokes. Professional premium sports identity, confident and timeless, carefully designed negative space, crisp vector-like edges, balanced symmetry, readable at 32px and 64px. The shield can have a dark solid interior with ivory lettering and subtle gold edging; its outside background MUST be true transparent alpha, never white, no checkerboard. Fill approximately 84–90% of the square with the emblem, centered with clean equal clear space. Make the four-letter wordmark large and integrated, no tiny text. Flat vector-style identity with very restrained depth if helpful, not a mockup, no floating objects, no photorealism, no metallic chrome, no neon, no gratuitous stars/crowns/laurels, no additional words/numbers, no watermarks. Deliver a single finished icon on transparency suitable for macOS Dock and Windows taskbar, not a presentation sheet.
